# SalesforceQOL

A collection of local, zero-deploy quality-of-life tools for working with
Salesforce orgs.

| Tool | What it does |
|------|--------------|
| [apex-org-diff](apex-org-diff/) | Compare Apex classes between two org folders (Monaco diff viewer) |
| [lwc-org-diff](lwc-org-diff/) | Compare Lightning Web Components between two org folders (bundle-aware Monaco diff viewer) |
| [sf-dependency-graph](sf-dependency-graph/) | Obsidian-style dependency graph for one org folder - Apex/LWC blast-radius analysis |

`samples/` holds shared fixture orgs used by apex-org-diff's and
lwc-org-diff's dev scripts. `sf-dependency-graph` ships its own fixture
(generated by its `scripts/create_fixture_org.py`) since it needs real
cross-references between classes/components to have anything to graph. Each
tool is self-contained (its own `requirements.txt`, `README.md`, and local
web server) - see its own README for setup and usage.
